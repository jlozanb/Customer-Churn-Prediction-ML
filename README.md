## Overview

Predictive analytics project developed to identify customers with a higher probability of churn and understand the main factors influencing customer retention.

The project applies machine learning techniques to customer data, transforming historical information into predictive insights that can support retention strategies and business decisions.

The final output provides churn predictions and model interpretation to identify the main drivers behind customer attrition.

## Features

- Exploratory data analysis
- Customer behavior analysis
- Data cleaning and preprocessing
- Feature engineering
- Classification model development
- Model evaluation and comparison
- Churn probability prediction
- Customer retention insights

## Technologies

- Python
- Pandas
- NumPy
- Scikit-Learn
- Machine Learning
- Predictive Analytics
- Data Visualization

## Workflow

- Customer data is loaded and explored to identify churn patterns.
- Data preprocessing and feature engineering are performed.
- Machine learning classification models are trained.
- Models are evaluated using performance metrics.
- Predictions are analyzed to identify customers with higher churn risk.

## Model Analysis

The project evaluates:

- Churn probability
- Feature importance
- Classification performance
- Model comparison
- Customer risk segmentation

## Project Purpose

The objective of this project was to develop a predictive model capable of identifying customers at risk of leaving and understanding the factors associated with churn.

The project aims to demonstrate how machine learning can support proactive customer retention strategies and improve business decision-making.
